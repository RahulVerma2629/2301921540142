# Campus Notification System Evaluation Backend Proxy

An optimized Node.js reverse-proxy microservice to connect seamlessly with the protected AffordMed campus broadcast metrics service.

## Operations Matrix
1. Handles security bearer authorization encapsulation off-client.
2. Ingests raw dates and injects live descending weight matrices.
3. Passes logs to the common shared file system pipeline.
